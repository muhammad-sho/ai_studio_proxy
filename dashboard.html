Connect any app

Any tool that speaks the Gemini API works — automations, SDKs, scripts, chat UIs. Change only two things: the URL points to this server, and the key is one of your client keys.

Proxy URL: —
Auth header: x-proxy-api-key
Your keys: generate them in the Client Keys tab

Send a chat / text request

curl -X POST http:///v1beta/models/gemini-2.0-flash:generateContent \
  -H "Content-Type: application/json" \
  -H "x-proxy-api-key: YOUR-CLIENT-KEY" \
  -d '{
    "contents": [
      {
        "parts": [
          { "text": "Say hello" }
        ]
      }
    ]
  }'

Swap gemini-2.0-flash for any model from the list below. The response is Google's response, unchanged.

List available models

curl http:///v1beta/models \
  -H "x-proxy-api-key: YOUR-CLIENT-KEY"

Answers instantly from the local cache and refreshes from Google in the background once a day. The sync time is shown on the Overview tab.

JavaScript (fetch)

const response = await fetch("http:///v1beta/models/gemini-2.0-flash:generateContent", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-proxy-api-key": process.env.PROXY_KEY
  },
  body: JSON.stringify({
    contents: [{ parts: [{ text: "Say hello" }] }]
  })
});
const data = await response.json();
console.log(data.candidates[0].content.parts[0].text);

Python (requests)

import requests

response = requests.post(
    "http:///v1beta/models/gemini-2.0-flash:generateContent",
    headers={"x-proxy-api-key": PROXY_KEY},
    json={"contents": [{"parts": [{"text": "Say hello"}]}]},
)
data = response.json()
print(data["candidates"][0]["content"]["parts"][0]["text"])

Response codes

StatusMeaning
200Success — Google's answer is returned unchanged.
401The client key is missing or invalid. Check the Client Keys tab.
503No Gemini API keys are configured at all. Even cooled-down keys are tried first as a last resort.
502Gemini did not respond on any attempted key (network/timeout). Google's own error responses are relayed to you exactly as received.

Tip: when a key hits a limit or an outage, the proxy already retries the request on another key before answering.
